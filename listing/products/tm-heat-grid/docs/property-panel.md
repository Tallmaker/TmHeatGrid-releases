# Property panel

Open the property panel in edit mode to set the color, the labels and the grid.

## Color

- Choose a sequential or a diverging color scale.
- Choose a theme palette, red-yellow-green, or your own colors.
- Set the color range automatically, or set a minimum, a maximum and a midpoint.

## Cell labels

- Choose the inline, stacked or primary-only layout.
- Hide labels for cells where the secondary value is null, zero or below a threshold you set.

## Grid

- Set the cell spacing and the corner radius.
- Show or hide empty rows and empty columns.
- Set **Maximum rows** up to 50,000 rows. The default is 10,000 rows.
