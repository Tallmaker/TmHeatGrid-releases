# Selections and keyboard

Hover over a cell to read the column value, the row value and both measures.

## Select values

1. Click a cell to select its column value and its row value.
2. Click a column label or a row label to select that value.
3. Drag across cells to select a range.

## Use the keyboard

Press Tab to enter the grid. Use the arrow keys to move between cells. Press Enter or Space to select the cell in focus. Press Esc to leave the grid.

Export the data and use **View data** from the Qlik menu.
